8.3 สร้าง External Table ใน Hive (ผ่าน Beeline):

- เชื่อมต่อเข้า HiveServer2 ผ่าน Beeline:
beeline -u "jdbc:hive2://localhost:10000/default" -n root

-SQL-
# สร้าง database

CREATE DATABASE IF NOT EXISTS stores_db;

USE stores_db; <select database>

CREATE EXTERNAL TABLE IF NOT EXISTS store_tb (
    id INT,
    name STRING,
    quantity INT
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ','
STORED AS TEXTFILE
LOCATION '/lab3'
TBLPROPERTIES ("skip.header.line.count"="1");

ROW FORMAT DELIMITED FIELDS TERMINATED BY ',': ระบุว่าแต่ละคอลัมน์คั่นด้วยจุลภาค
STORED AS TEXTFILE: ชนิดไฟล์เป็นข้อความธรรมดา
LOCATION '/lab3': ชี้ไปที่ โฟลเดอร์ (ไม่ต้องระบุชื่อไฟล์ Hive จะอ่านทุกไฟล์ในโฟลเดอร์นี้)
TBLPROPERTIES ("skip.header.line.count"="1"): สั่งข้ามบรรทัด Header (แถวแรก)

Note: EXTERNAL TABLE จะไม่สามารถ update หรือ delete ได้เพราะข้อมูลจริงๆ จะอยู่ใน file students_data.csv
